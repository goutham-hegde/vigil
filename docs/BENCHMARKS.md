## Published results on LANL

Protocols differ between papers and from this benchmark; each row notes how. These are context, not head-to-head comparisons.

| work | metric | value | protocol notes |
|---|---|---:|---|
| Tuor et al. 2017, arXiv:1712.00557 | ROC-AUC | 0.98 | Event-level (log line) red-team detection with a character-based RNN language model, the same granularity as this benchmark. Trained online over the stream rather than on a fixed earlier window, and reports ROC-AUC without average precision, which flatters any model at this class imbalance. Their comparisons are against Isolation Forest and PCA. |
| Euler (King & Huang), NDSS 2022, Table VI, GCN+GRU | ROC-AUC / AP / TPR at FPR | 0.9912 / 0.0523 / 86.10% at 0.5698% | Edge-level link detection on hourly graph snapshots, not per-event scoring, so the positives and negatives being counted are different objects. Trained on all snapshots before the first red-team edge (roughly the first two days), where this benchmark trains on days 0-7. Note the AP of 0.05 next to an AUC of 0.99: the same gap this report warns about. |
| Euler (King & Huang), NDSS 2022, Table VI, SAGE+GRU | ROC-AUC / AP / TPR at FPR | 0.9847 / 0.0200 / 86.30% at 1.6542% | Their best link *prediction* configuration. The prediction test scores each true edge against an equal number of randomly sampled negative edges, so its base rate is nothing like a real event stream, where positives are about 1 in 1.5 million. |
| Unknown Authentication rule, as reported in Euler Table VI | TPR at FPR | 72.00% at 4.400% | Flags any edge absent from the training data: the same idea as this benchmark's `first_seen_edge` baseline, and the most directly comparable row here, though still edge-level rather than per-event. |
| Bowman et al., cited as GL-GV in Euler Table VI | TPR at FPR | 85.00% at 0.900% | Graph-learning baseline reported by Euler rather than measured here; edge-level, and the training window is the pre-attack period. |
